一、 核心痛点与解决思路

用户在手机端预订酒店面临三大痛点：多平台差价暗坑（差价 30~100 元）、时间维度剧烈波动（周末暴涨 30%~85%、国庆满房熔断）、千人千面假低价（非登录态假价格）。

破局架构：移动端原生体验 H5/PWA + 客户端全局会员资产图层 + 正规联盟 CPS 优先 / 爬虫低频兜底 + 断源降级隔离熔断 + 微信双通道容灾盯盘。

三、 Phase 0 数据源探针调研与风控降级预案 (P0-1 闭环)

  • 携程旅行 (Ctrip)：开放联盟个人站长通道已开放（需身份证与备案域名/公众号），佣金率 3%~6%；爬虫通道遇 AntiBot 自动触发断源熔断器，隔离该列并不参与比价。
  • 美团酒店 (Meituan)：美团分销联盟支持生成短链与小程序码；爬虫若遇 _lxsdk_s 或设备指纹校验失败，立即标灰“🔧 渠道维护中”，底价在健康渠道中重新校准。
  • 华住会直营 (Huazhu)：全网价格最硬、最稳定的直营底价锚点；提供金卡 88 折+单早、铂金 85 折+双早作为决策基准。
  • 飞猪旅行 (Fliggy)：严格克制，不强攻阿里盾，等待正规官方 API 准入。
