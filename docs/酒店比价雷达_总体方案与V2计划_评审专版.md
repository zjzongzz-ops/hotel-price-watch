## 一、 核心痛点与解决思路

在手机端预订国内酒店时，普通用户面临三大核心困境：
1. **多平台差价暗坑**：同一家酒店的标准大床房，携程、美团、华住官方直营之间经常存在 30~100 元不等的差价，且含早政策与取消条款模糊。
2. **时间维度波动剧烈**：周末溢价普遍在 30%~85%，节假日（如国庆）甚至暴涨 150% 以上或触发满房熔断。用户很难直观知道“哪天住最划算”。
3. **千人千面“假低价”陷阱**：各平台的会员等级（携程钻石、美团神会员、华住铂金）会导致最终实付价天差地别。非登录态抓取的公开标价往往不能代表真实支出。

**本项目的破局思路**：
采用**“移动端优先的高保真 H5 + 客户端全局会员资产图层 + 正规联盟 CPS 优先 / 爬虫低频兜底 + 断源降级隔离熔断 + 微信双通道容灾盯盘”**。严守合规底线，杜绝收集用户密码，以真实稳定的架构实现极致体验。

## 三、 Phase 0 数据源探针调研与风控降级机制 (P0-1 闭环)

针对国内三大渠道与直营渠道的实际探针测试与官方通道调研结论如下：

1. **华住会官方直营 (Huazhu)**：
   - **定位**：真底价锚点。各大 OTA 上的全季、汉庭、桔子均受华住控价政策约束。
   - **风控等级**：中。数据结构透明，会员体系公开（星会员 95 折、金卡 88 折+单早、铂金 85 折+双早）。
   - **结论**：**优先准入**。抓取基础公开价后前端套用会员公式，基于规则估算到手价。
2. **美团酒店 (Meituan)**：
   - **定位**：低星、民宿、单早套餐覆盖第一。
   - **官方通道**：已验证美团分销联盟（`union.meituan.com`），支持个人推广位转链与小程序口令。
   - **降级预案**：爬虫通道若遭遇 `MTGSig` 或 `_lxsdk_s` 校验封禁，**触发熔断器并自动标灰“🔧 渠道维护中”，严格剔除出全网最低价排序**，剩余渠道重新计算底价。
3. **携程旅行 (Ctrip)**：
   - **定位**：全国覆盖基准盘，商旅退改宽松。
   - **官方通道**：已验证携程开放联盟（`u.ctrip.com`），个人站长凭身份证与备案域名/公众号即可入驻，佣金率 3%~6%。
   - **降级预案**：遇 AntiBot 错误码自动降级隔离，请求间隔随机抖动（3~8秒），严格走本地缓存层。
4. **飞猪旅行 (Fliggy)**：
   - **定位**：目标态（暂缓直连）。阿里 MTOP WUA 逆向成本极高，坚决不写暴力爬虫，后续申请官方淘宝客/阿里百川正规 API。

## 五、 V2 功能升级规划与匹配容错交付项 (P2-7 闭环)

V2 升级聚焦于**“突破 20 家基准酒店，支持全网任意酒店一键比价”**：

```
[用户在美团/携程/飞猪复制分享链接] 
       │
       ▼
[点击雷达顶部【一键粘贴并比价】]
       │
       ▼
[V2 智能解析引擎 (server/parser.py)]
   ├─ 自动识别来源平台 (携程/美团/飞猪/华住)
   ├─ 智能剥离营销废话与追踪参数
   └─ 实体提取：城市名 + 酒店全称 + 房型规格
       │
       ▼
[跨平台酒店身份匹配引擎 (P2-7 容错规约)]
   ├─ 强置信度匹配 (品牌 + 城市 + 分店全名一致) ──> 正常纳入比价卡片
   └─ 弱置信度 / 存疑匹配 ──> 标灰显示【待确认】，严禁跨店错误比价！
       │
       ▼
[动态跨平台询价调度器] ──> [即时生成比价卡片并置顶] ──> [30天走势与微信盯盘]
```

### 关键交付项：
1. **多平台特征解析器 (`server/parser.py`)**：覆盖各平台主流分享文案正则与短链还原。
2. **跨平台匹配容错守则**：匹配置信度不足一律标灰待确认，宁缺毋滥。
3. **手机端剪贴板快捷交互**：顶部一键读取剪贴板，带快速演示示例。
4. **动态卡片与走势预测生成**：对新增酒店即时生成三渠道价格对比卡片。

- **前端静态托管**：**Cloudflare Pages + 自定义域名**（国内直连速度优异，自带全球 CDN 与免费 SSL），彻底规避 Vercel/Netlify 国内不可达问题。
- **独立盯盘调度 (Off-PC Cron)**：
  - **GitHub Actions Scheduled Workflow**（`.github/workflows/hotel_watcher.yml`）：每日早 09:00 与晚 18:00 定时执行，直接调用 `server/watcher_cron.py`，与本地电脑完全解耦。
